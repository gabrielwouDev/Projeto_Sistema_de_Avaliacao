# Projeto_Sistema_de_Avaliacao

## O que é
Este projeto consiste no desenvolvimento de uma plataforma web de avaliação e descoberta de filmes, séries e animes, inspirada em plataformas como o IMDb. Desenvolvido como parte de um projeto escolar com duração de dois meses, o trabalho utiliza a metodologia ágil Scrum, com o desenvolvimento organizado em ciclos de trabalho (sprints).

O objetivo é criar uma plataforma na qual os usuários possam explorar um catálogo de mídias, avaliar seus títulos favoritos e compartilhar suas opiniões, contribuindo para a construção de avaliações coletivas que auxiliem outros usuários na escolha do que assistir.

## Funcionalidades planejadas
- Catálogo de mídias: exibição de filmes, séries e animes em cards padronizados, organizados em sequência, proporcionando uma experiência de navegação inspirada em serviços de streaming.
- Barra de pesquisa: busca de títulos no catálogo de forma rápida e intuitiva.
- Sistema de autenticação: criação e acesso a contas de usuário por meio de uma tela de login.
- Avaliações por usuário: possibilidade de atribuir notas aos títulos, com avaliações associadas à conta de cada usuário.
- Média de avaliações: cálculo e exibição da nota média de cada título em formato de estrelas, com base nas avaliações registradas.
- Comentários opcionais: possibilidade de adicionar comentários junto às avaliações, permitindo que os usuários compartilhem suas opiniões sobre cada título.
- Filtros por categoria e gênero: navegação por tipos de mídia, como filmes, séries e animes, além de gêneros como romance e ação.
- Aba Em Alta: seção dedicada aos títulos com maior destaque, considerando a quantidade de avaliações e a nota dos usuários.

O projeto busca aplicar, na prática, conceitos de desenvolvimento web, organização de banco de dados, gerenciamento de projetos e trabalho em equipe, seguindo um processo iterativo de planejamento, desenvolvimento e revisão a cada sprint.
